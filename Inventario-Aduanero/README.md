# Laboratorio 3: Sistema de Inventario Aduanero

Proyecto académico de Bases de Datos. Consiste en diseñar una base de datos relacional para registrar información aduanera y construir un agente de IA en n8n que permita consultar los datos mediante preguntas en lenguaje natural.

## Herramientas

- Supabase con PostgreSQL
- n8n
- diagrams.net (draw.io)

## Carpetas

- `investigacion/`: investigación sobre bases de datos, SQL, gestores, n8n y el dominio aduanero.
- `diagrama/`: diagrama Entidad-Relación del sistema.
- `sql/`: script para crear las tablas, insertar datos y realizar consultas.
- `n8n/`: workflow exportado desde n8n en formato JSON.
- `evidencia/`: capturas o video de las pruebas del agente.

## Entregables

1. Investigación en PDF de 3 a 6 páginas, con fuentes y el apartado “Uso de IA”.
2. Diagrama Entidad-Relación en PNG, JPG o PDF.
3. Script SQL con tablas, datos de prueba y al menos 8 consultas.
4. Workflow de n8n exportado como JSON.
5. Evidencia de al menos 8 preguntas respondidas por el agente.

## Nota

El laboratorio no requiere React. Los requisitos principales son la base de datos, el diagrama y el agente de IA en n8n.
